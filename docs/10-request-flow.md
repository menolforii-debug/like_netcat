# 10. Путь запроса (URL → HTML)

## Зачем это существует

Документ описывает, как из URL получается HTML: какие сущности участвуют и где их настраивать.

## Как это работает (кратко)

1. Определяется сайт по `HTTP_HOST`.
2. По `REQUEST_URI` выбирается раздел (`section`).
3. Для раздела загружаются инфоблоки и их компоненты.
4. Компонент рендерит шаблон `list`/`single`.
5. Макет оборачивает результат и отдаёт HTML.

## Примеры

### Пример: базовый поток

```text
GET /news/
  └─ site: example.com
  └─ section: /news/
  └─ infoblock: news (component: News)
  └─ template: list
  └─ layout: default
```

### Типовой сценарий

- Добавить в раздел два инфоблока: новости и акции.
- На фронте обе секции отрисуются в порядке сортировки инфоблоков.
