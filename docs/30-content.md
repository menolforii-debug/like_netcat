# 30. Контентные сущности

## Зачем это существует

Документ описывает основные сущности контента и то, как они связаны между собой.

## Как это работает (кратко)

- Контент хранится в `objects` и привязан к инфоблокам.
- Инфоблоки размещаются в разделах и используют компонент с выбранным представлением.
- Для смены HTML используется шаблон компонента или макет.

## Основные сущности

- **Раздел** — страница и место для инфоблоков.
- **Инфоблок** — экземпляр компонента в разделе, ключ обязателен и обычно формируется из названия (при очистке ключа можно снова включить автоподстановку).
- **Объект** — запись с данными компонента.
- **Сниппет** — врезка HTML/JS/PHP для вставки через `insert_snip()`.

## Примеры

### Пример: список объектов инфоблока

```sql
SELECT id, data_json, status
FROM objects
WHERE infoblock_id = 7 AND is_deleted = 0
ORDER BY id ASC;
```

### Типовой сценарий

- Создать инфоблок “Новости”.
- Добавить объекты с полями `title`, `body`.
- Вывести список через шаблон компонента.
- Для массовой очистки объектов используйте кнопку «Удалить все» во вкладке «Контент».
