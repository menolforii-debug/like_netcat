# 30. Контент: sections → infoblocks → objects

## Зачем это существует

Этот уровень описывает, как хранится и выводится контент.

## Когда использовать

- Нужно понять, где находится контент и как он связан с компонентами.

## Когда НЕ использовать

- Когда нужно править макеты и общий HTML — это `docs/50-templates-layouts.md`.

## Как это работает (кратко)

- `sections` — дерево разделов сайта.
- `infoblocks` — виджеты внутри разделов.
- `objects` — элементы контента внутри инфоблоков.

## Примеры

### Пример: получение объектов инфоблока

```php
$items = objects_list([
  'infoblock_id' => 10,
  'status' => 'published',
]);
```

### Типовой сценарий

1. Создать раздел “Новости”.
2. Добавить инфоблок “Новости” (компонент `news`).
3. Добавить объекты (новости) в инфоблок.

### Как делать НЕ надо

```php
// НЕ выводите объекты инфоблока через прямой SQL из шаблона
$rows = DB::fetchAll('SELECT * FROM objects');
```

## Частые ошибки

- Ожидание, что `per_page` сделает пагинацию — он лишь ограничивает выборку.
