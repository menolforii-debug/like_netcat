# 55. Макеты

## Зачем это существует

Макеты отвечают за HTML‑каркас страницы и подключение общих блоков: шапки, меню, подвала, скриптов.

## Сущности и файлы

### Макет страницы

Файл макета хранится в:

```
templates/layouts/<layout>.php
```

Макет вызывается через `Layout::render()` и получает контекст страницы.

### Навигационный файл макета

Опциональный файл:

```
templates/layouts/<layout>.nav.php
```

Он подключается перед основным макетом и может подготовить данные меню или доп.переменные.

## Переменные в макете

В шаблоне макета доступны:

- `$ctx` — контекст страницы.
- `$body` — callable, который выводит HTML инфоблоков.

Ключи в `$ctx`:

- `title` — заголовок страницы.
- `meta` — массив SEO‑данных (`description`, `keywords`, и др.).
- `site` — текущий сайт.
- `section` — текущий раздел.
- `visual` — визуальные настройки (наследуются от сайта и раздела).
- `children` — дочерние разделы.

## Как выбирается макет

1. Сначала проверяется макет раздела (`sections.extra_json.layout`).
2. Если у раздела макет не задан, берётся макет сайта.
3. Если и у сайта нет макета, используется `default`.

Файлы макетов должны существовать в `templates/layouts/` — иначе произойдёт откат к `default`.

## Пример макета

```php
<?= Layout::renderDocumentStart($ctx['title'] ?? '', $ctx['meta'] ?? []) ?>
<main class="container py-4">
  <?php $body(); ?>
</main>
<?= Layout::renderDocumentEnd() ?>
```

## Системные настройки сайта и раздела

Системные настройки хранятся в `sections.extra_json` и управляются из админки.

### Перечень переменных сайта

- `site_domain` — основной домен сайта.
- `site_mirrors` — список зеркал домена.
- `site_enabled` — флаг включения сайта.
- `site_offline_html` — HTML, который показывается при отключённом сайте.
- `layout` — макет дизайна по умолчанию.
- `visual_settings` — визуальные настройки сайта.

### Перечень переменных раздела

- `layout` — макет дизайна для конкретного раздела.
- `visual_settings` — локальные визуальные настройки раздела (переопределяют настройки сайта).

### Пример системных настроек (SQL)

```sql
UPDATE sections
SET extra_json = '{
  "site_domain": "example.com",
  "site_mirrors": ["www.example.com"],
  "site_enabled": true,
  "site_offline_html": "<h1>Сайт временно недоступен</h1>",
  "layout": "marketing",
  "visual_settings": {
    "primary_color": "#1a73e8",
    "logo": "/files/logo.svg"
  }
}'
WHERE id = 1;
```

### Пример переопределения макета разделом

```sql
UPDATE sections
SET extra_json = '{"layout": "landing"}'
WHERE id = 12;
```
