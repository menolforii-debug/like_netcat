# Тест-сценарии (manual)

## Домены сайтов
1. Создать сайт A с доменом `example.com`.
2. Создать сайт B с доменом `example.com` → должно отказать.
3. Удалить сайт A рекурсивно.
4. Назначить домен `example.com` сайту B → должно разрешить.

## Рекурсивное удаление разделов
1. Создать раздел с инфоблоком и объектами.
2. Удалить раздел рекурсивно.
3. Проверить, что в БД не осталось `infoblocks` и `objects`, связанных с этим разделом.

## Удаление компонента
1. Создать компонент с ключом `news_test`.
2. Удалить компонент.
3. Проверить, что директория `templates/news_test/` отсутствует.
