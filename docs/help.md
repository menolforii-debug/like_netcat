# Справка по документации проекта

Этот файл — индекс документации. Раздел «Справка» в админке показывает список файлов,
а при клике загружает выбранный документ.

## Архитектура

- `docs/architecture.md` — входные точки, выбор сайта/раздела, рендеринг, события.

## Макеты дизайна

- `docs/templates.md` — макеты, доступные переменные и функции, шаблоны навигации.

## Врезки

- `docs/snippets.md` — хранение, выполнение PHP‑кода, наследование контекста, примеры.

## Компоненты

- `docs/components.md` — структура компонентов, представления, шаблоны list/single, `system_tpl`.

## Функции / API

- `docs/functions-api.md` — список функций/хелперов, доступных в макетах/компонентах/врезках.
- `docs/objects-api.md` — подробное описание `nc_objects_list()` и фильтров.

## Остальные документы

- `docs/admin.md` — обзор админки и её разделов.
- `docs/data-model.md` — модель данных и таблицы.
