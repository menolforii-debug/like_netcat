# CLI утилита bin/cms

## Зачем это существует

Утилита упрощает разработку и администрирование: миграции, разделы, пользователи.

## Когда использовать

- Нужно быстро создать раздел или пользователя без админки.

## Когда НЕ использовать

- В продакшене без контроля доступа.

## Как это работает (кратко)

Скрипт `bin/cms` подключает `app/bootstrap.php` и выполняет команду.

## Примеры

### Пример: список разделов

```bash
php bin/cms sections:list
```

### Пример: создать пользователя

```bash
php bin/cms users:add --login=admin --pass=admin --role=admin
```

### Как делать НЕ надо

```bash
# НЕ храните пароли в истории shell
php bin/cms users:add --login=admin --pass=12345
```

## Частые ошибки

- Забывают кавычки в `--title="Новости"`.
