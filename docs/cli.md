# CLI утилита bin/cms

## Зачем это существует

Утилита упрощает разработку и администрирование: миграции, разделы, пользователи.

## Как это работает (кратко)

Скрипт `bin/cms` подключает `app/bootstrap.php` и выполняет команду.

## Примеры

### Пример: список разделов

```bash
php bin/cms sections:list
```

### Пример: создать пользователя

```bash
php bin/cms users:add --login=admin --pass=admin --role=admin
```
