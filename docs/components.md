# Компоненты и представления

Компонент описывает структуру данных и набор шаблонов для вывода контента.

## Структура компонента

- `components.fields_json` — список полей (имя, тип, обязательность, опции).
- `components.views_json` — список имён представлений (синхронизируется с БД).

## Представления компонентов

Каждое представление хранится в `component_views` и содержит:

- `list_tpl` — шаблон списка;
- `single_tpl` — шаблон полного отображения;
- `system_tpl` — системные настройки (PHP‑код).

При сохранении админка формирует файл:

```
templates/component/<keyword>/<view>.php
```

## Системные настройки (`system_tpl`)

Код из `system_tpl` добавляется **в конец** сформированного PHP‑файла, после выбора
между `list` и `single` режимом. Это позволяет:

- объявлять функции и переменные;
- выполнять дополнительную логику;
- готовить данные для шаблона.

## Режимы list/single

Шаблон получает переменные:

- `$isSingle` — режим одного объекта;
- `$objects` — список объектов в режиме list;
- `$object` — первый элемент `$objects` в режиме single.

Полный список переменных и функций — в `docs/templates.md` и `docs/functions-api.md`.
