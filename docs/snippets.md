# Врезки (snippets)

Врезки — это фрагменты PHP/HTML/JS, которые хранятся в базе данных и могут быть
вставлены в макеты или шаблоны компонентов.

## Где редактируются

Раздел **«Врезки»** в админке. Каждая врезка имеет:

- `keyword` — уникальный ключ;
- `content` — содержимое (PHP/HTML/JS).

## Как вставлять

Врезка выводится через функцию:

```php
<?php insert_snip('promo'); ?>
```

Можно передать собственные переменные:

```php
<?php insert_snip('promo', ['title' => 'Скидки недели', 'items' => $items]); ?>
```

## Контекст выполнения

- Если массив `$vars` не передан, врезка наследует переменные текущего шаблона.
- Функция **печатает** результат и **возвращает** его строкой.
- Врезка выполняется как PHP‑код (через `eval`), поэтому доступен любой PHP.

## Безопасность

Содержимое врезки **не экранируется** и может выполнять произвольный код.
Используйте её только для доверенного контента.
