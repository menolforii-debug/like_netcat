# 70. Типовые сценарии

## Зачем это существует

Сводка частых задач, которые встречаются при работе с CMS.

## Как это работает (кратко)

Сценарии построены вокруг типовых задач: добавление контента, отладка выборок, правка шаблонов.

## Примеры

### Сценарий: ограничить вывод 10 объектов

```php
// В админке задайте per_page = 10 для инфоблока
// или в шаблоне используйте фильтр:
$items = objects_list(['infoblock_id' => 10, 'status' => 'published', 'limit' => 10]);
```

### Сценарий: использовать $f_* переменные в list

```php
<?php foreach ($objects as $obj): ?>
  <?php $setFields($obj); ?>
  <h3><?= htmlspecialchars((string) $f_title, ENT_QUOTES, 'UTF-8') ?></h3>
<?php endforeach; ?>
```
