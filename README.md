# Like Netcat — минималистичная CMS на PHP + SQLite

Это компактная CMS, ориентированная на разработчиков: контент хранится в SQLite, структура выводится через компоненты и шаблоны, а документация встроена прямо в админку.

## С чего начать

1. Прочитайте вводный документ: **`docs/00-introduction.md`** — он объясняет логику системы и ключевые термины.
2. Дальше переходите к пути запроса: **`docs/10-request-flow.md`**.
3. Затем изучите базу данных: **`docs/data-model.md`**.
4. Полный справочник API: **`docs/60-api-reference.md`**.

> Админка показывает документы из `docs/` — список формируется автоматически (см. `docs/help.md`).

## Краткое описание архитектуры

- Данные организованы как: `sections → infoblocks → objects`.
- Компоненты описывают структуру данных, а `component_views` — набор шаблонов.
- Макеты (`layouts`) отвечают за общий каркас страницы.
- Врезки (`snippets`) — небольшие фрагменты HTML/JS/PHP.
