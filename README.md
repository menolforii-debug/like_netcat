# `Like Netcat` — минималистичная система управления контентом на `PHP` + `SQLite`

Это компактная система для разработчиков: контент хранится в `SQLite`, структура выводится через компоненты и шаблоны, а документация встроена в админку.

## С чего начать
Начинайте с файла `docs/00-overview.md` и двигайтесь по руководству:

1. `docs/00-overview.md` — обзор и термины.
2. `docs/10-runtime-architecture.md` — рантаймы и точки входа.
3. `docs/20-bootstrap-and-install.md` — запуск и БД.
4. `docs/30-request-flow.md` — поток запроса.
5. `docs/40-templates-and-components.md` — шаблоны компонентов.
6. `docs/50-system-php-contract.md` — контракт `system.php`.
7. `docs/60-layouts.md` — макеты страниц.
8. `docs/70-snippets.md` — врезки.
9. `docs/80-admin-handbook.md` — админка.
10. `docs/90-database.md` — база данных.
11. `docs/95-security.md` — безопасность.
12. `docs/99-known-issues-and-todos.md` — известные проблемы.

> Админка показывает документы из `docs/` автоматически (раздел «Справка»).
