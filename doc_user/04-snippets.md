# Врезки

Врезки — это PHP-файлы в каталоге:
`templates/snippets/<name>.php`

Подключение в шаблонах:
```php
<?php echo insert_snip('footer'); ?>
```

## Что доступно во врезке
`insert_snip($name, $vars)` работает так:
- если `$vars` передан, переменные из массива становятся доступными внутри врезки;
- если `$vars` пуст, используется текущая область `_snip_scope` (наследование контекста из макета/компонента).

Поэтому во врезке обычно доступны переменные из места вызова:
- при вызове из макета: `$ctx`, `$title`, `$meta`, `$site`, `$body` и связанные;
- при вызове из компонента: `$section`, `$site`, `$infoblock`, `$component`, `$items/$object`, `$f_*`, `$helpers`, `$cc_env` и т.д.

## Функции, доступные во врезках
- стандартные PHP-функции;
- helper-функции проекта, подключённые в public bootstrap (например `insert_snip`, `browse_messages`, `resolveTemplatePath`).

## Безопасность
- имя врезки проверяется по маске `A-Za-z0-9_-`;
- путь проверяется через `realpath` и ограничивается `templates/snippets`.

## В админке
Раздел `Врезки`:
- список врезок;
- создание/редактирование;
- удаление.
