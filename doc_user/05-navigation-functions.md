# Функции навигации

Основные функции/методы для навигации:
- `Layout::getMainMenuItems($ctx, $maxDepth)` — построение меню;
- `Layout::renderNavbar($brand, $links)` — вывод базовой панели;
- `Layout::renderSectionHeader($section, $children)` — заголовок раздела.

Используются в макетах (`templates/layouts/*.php`).
