# Инициализация и установка

Кратко:
- публичная точка входа: `public_html/index.php`;
- админка: `public_html/admin.php`;
- база данных: `var/app.sqlite`.

## Минимальные требования
- PHP 8+
- права на запись: `var/`, `templates/`, `public_html/files/`.

## Поведение инициализации при отсутствии БД
Если файла `var/app.sqlite` нет, приложение выполняет первичную инициализацию.

### Что делает общий bootstrap
- создаёт `var/app.sqlite`;
- применяет `app/shared/schema.sql`;
- создаёт сайт и корневые разделы `index` и `404`.

### Что делает public bootstrap дополнительно
- подготавливает дефолтные шаблоны макета:
  - канонические источники: `app/admin/resources/default_layouts_templates/default.php` и `default.nav.php`;
  - затем копии в `templates/layouts/default/default.php` и `templates/layouts/default/default.nav.php` (если отсутствуют);
  - и рабочие файлы `templates/layouts/default.php` и `templates/layouts/default.nav.php` (если отсутствуют);
- создаёт дефолтный сайт (если не был создан на предыдущем шаге);
- создаёт дефолтные визуальные поля (`visual_fields`) при пустой таблице.

## Что важно для эксплуатации
- если БД уже существует, повторно схема и дефолтные данные не инициализируются автоматически;
- изменения в `schema.sql` и структуре данных для существующей БД вносятся отдельно (миграциями/скриптами);
- папки с шаблонами и файлами должны оставаться доступными на запись для операций из админки.
