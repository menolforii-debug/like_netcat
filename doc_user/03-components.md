# Компоненты

Шаблоны компонентов лежат в:
`templates/component/<keyword>/<view>/`

Файлы представления:
- `list.php`
- `single.php`
- `system.php`

## В админке
Раздел `Компоненты` позволяет:
- создавать компонент;
- добавлять/удалять представления (`view`);
- редактировать `list.php`, `single.php`, `system.php`.
